# ぶるりぱ名言集カルタ (Bururipa Quotes Karuta)

ブラウザ一本で完結し、GitHub Pages などの静的ホスティングでそのまま公開・対戦できるルーム式オンラインカルタゲームです。

## 主な機能
- **ルーム式オンラインマッチング（PeerJS / WebRTC）**：サーバー構築不要。ホストが発行した6桁のルームIDまたは招待URLで最大4名までリアルタイム対戦。
- **体系的なゲームフロー**：ロビー → 待機室（ルール設定・準備完了） → 対戦盤面（音声読み上げ＋タイマー＋キーボード操作対応） → 結果集計・再戦。
- **ソロ / CPU対戦モード**：1人でも難易度別（やさしい・ふつう・つよい・タイム計測のみ）で練習可能。
- **札リストの外部ファイル化（`data/cards.json`）**：札の追加・編集をGitHub上で管理できるほか、ブラウザ上の「札の管理」画面からJSONのインポート・エクスポートも可能です。

## ファイル構成
```text
karuta-online/
├── index.html        # メインHTML
├── css/
│   └── style.css     # 和モダンUIスタイル
├── js/
│   ├── app.js        # ゲーム進行・UI・札エディタ制御
│   ├── network.js    # PeerJS ルーム式P2P通信
│   └── audio.js      # Web Speech API 読み上げ & Web Audio API 効果音
├── data/
│   └── cards.json    # 札のワードリスト（随時追加可能）
└── README.md
```

## GitHub Pages での公開手順
1. GitHub で新しいリポジトリを作成し、このフォルダ内のファイルをすべてプッシュします。
2. リポジトリの **Settings → Pages** を開き、Branch に `main`（ルート `/`）を指定して保存します。
3. 発行された `https://<username>.github.io/<repo>/` にアクセスすると、そのままオンライン対戦が遊べます。

## 札のワードを追加する方法
`data/cards.json` の `decks[].cards` 配列に以下の形式でオブジェクトを追加してコミットしてください。

```json
{
  "id": "unique_id",
  "head": "あ",
  "yomi": "読み札のテキスト",
  "tori": "取り札のテキスト",
  "reading": "よみあげようの ひらがな（省略可）"
}
```
※ アプリ右上の「📜 札の管理」画面から札を追加し、「📤 cards.json 出力」でダウンロードしたファイルをリポジトリの `data/cards.json` に上書きすることでも更新できます。
